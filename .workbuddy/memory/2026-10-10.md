## 教训（这轮踩的）

- **`替文` 改了文本却写回了旧的行列表** → README 半改状态，还留了个孤儿 ``` 代码围栏。
  根因：先 `行 = 文.splitlines()`，之后又对 `文` 做替换，最后写的却是 `行`。
  → **要么先替换文本、再切行；要么全程按行处理。别混。**
- **`python forge.py selftest` 这种标记会命中两处**（帮助块 + 自检节）→ 断言「唯一」当场拦下，改用更窄的标记。
  这一条正是脚本里 `assert 出现次数==1` 的价值：**它把「改了一处、漏了另一处」变成了硬错**。
