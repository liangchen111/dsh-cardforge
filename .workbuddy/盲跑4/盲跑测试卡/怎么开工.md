# 盲跑测试卡 · 怎么开工

一条命令生成的制卡工程。它分两层，改的地方不一样：

| 改什么 | 动哪里 |
|---|---|
| 卡的内容（世界观、条目、变量、正则） | `source/盲跑测试卡.spec.yaml` |
| 卡的界面（建卡器 / 面板 / 悬浮球长什么样） | `hud/` 下的文件 |
| 卡的颜色（皮肤） | `hud/主题.css` —— 由 `forge theme` 写，别手改 |
| 卡里接哪些现成机制 | 用 `forge add` / `forge drop`，别手改 |

**别手改卡文件**（`成品/盲跑测试卡.card.json`）—— 它是派生物，改了下一次构建就没了。
**也别手改 `模块账本.json`** —— 撤模块全靠它。

## 常用命令

```
python ../../../forge.py check  source/盲跑测试卡.spec.yaml     先跑这个，看有没有坑
python ../../../forge.py hud    .                           组装界面（出 预览.html）
python ../../../forge.py hud    . --写回                     组装并把正则写回 spec
python ../../../forge.py build  source/盲跑测试卡.spec.yaml 成品/盲跑测试卡.card.json
python ../../../forge.py check  成品/盲跑测试卡.card.json
python ../../../forge.py manual source/盲跑测试卡.spec.yaml     出人读手册
python ../../../forge.py mods   --工程 .                    看有哪些机制、接没接、要不要更新
python ../../../forge.py theme                              看有哪些皮肤
python ../../../forge.py theme  墨夜 .                       换皮肤（换完记得再 hud 一次）
python ../../../forge.py bundle .                           打成一个包，发给别人
```

（`../../../forge.py` 是制卡工具的 `forge.py`，不在本工程里 —— 用它的绝对路径，或者把它加进 PATH。）

## 顺序别乱

1. 先改 `source/盲跑测试卡.spec.yaml` 里〈核心 · 世界总纲〉那一条 —— 它每轮都进提示，
   是最该先想清楚的一条。
2. 把开场白写进 `hud/hud.conf.json` 的「开场白」正文（改完跑一次 `hud --写回`）。
3. 演示条目（名册 · 常用名字 / 规则 · 判定）用完就删或改成自己的。
4. 每改一轮跑一次 `check`；动了 `hud/` 就跑 `hud --写回` 再 `build`。

## 界面那一层是什么

`hud/hud.core.js` 是**通用骨架**：它把变量树原样画成面板，并提供一间建卡器
（把「玩家」那份档案填成表单，封缄即写回变量）与一颗常驻悬浮球。
它不含任何世界观内容 —— 你加变量，面板上就多一行，不用改代码。

想动界面就改 `hud/hud.css`（换颜色别改它，跑 `forge theme`）；改 `hud.core.js`
等于改机制，改之前先跑 `node 测试/test_core.js` 确认现在是绿的。

## 想加现成的机制

```
python ../../../forge.py mods --工程 .                        # 看有哪些、接没接
python ../../../forge.py add 骰子 source/盲跑测试卡.spec.yaml      # 接上骰子（改判定那一条）
python ../../../forge.py drop 骰子 source/盲跑测试卡.spec.yaml     # 后悔了就撤，接之前的样子还在账本里
```

接过模块之后，记得再跑一次 `hud --写回` 让界面带上它（脚本/样式落在 `hud/模块/` 下）。
**撤模块是精确的**：替换的那条还原成原样、新增的那条删掉、正则按 id 删、
界面文件与登记一并摘掉。你自己在 spec 里手写的东西，工具一律不动。

## 三条纪律

- **一条条目只干一件事。** 越长越该拆：拆开之后各自有自己的标题和「什么时候读我」。
- **常驻只放每轮必须看见的东西。** 其余一律走按需（不占每轮上下文）。
- **资料类走按需，规则类走关键词。** 关键词挑短词。

## 卡由什么构成

角色壳 + 设定库 +（可选）变量 +（可选）正则 +（可选）图片。
详见 `../../../文档/使用说明.md`。
