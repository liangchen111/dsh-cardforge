# 弃用 · 图形工作台

这里放的是**已经迁出主线**的「图形工作台」—— 那个开在浏览器里、给人点着做卡的界面。

## 为什么迁出

这个工具的形态是**教 AI 怎么开一张卡**，不是给人点的界面。现役形态只有三样：

1. `forge.py` 命令（**AI 跑**）
2. `向导/AI制卡规程.md`（**AI 读**的规程；外加 `SKILL.md` 门牌与 `示例卡稿.yaml`）
3. `插件/制卡工坊/`（给 ElecKoi 里的 AI 一个 `cardforge` 工具）

工作台不在这三样里。它从 2026-10-08 就冻结了（不跟进、不引流），2026-10-10（v0.27.0）
把它连同挂在自检里的第 **21 / 39 / 40** 项一起迁到这里，让主线彻底干净。

## 这里有什么

| 文件 | 迁出前的位置 |
|---|---|
| `ui.py` | `forge/ui.py`（本地 HTTP 服务 + 令牌校验；与前端配一对） |
| `前端/`（`index.html` / `app.css` / `app.js`） | `assets/工作台/` |
| `启动工作台.bat` | 工程根 |
| `前端冒烟.mjs` | `测试/前端冒烟.mjs`（DOM 桩真跑 `前端/app.js`） |

## 注意：它现在开不起来

摘除时一并做掉了三件事，直接跑 `启动工作台.bat` 或 `前端冒烟.mjs` 会失败：

1. `forge.py` 里的 `cmd_ui` 函数与命令表里的 `ui` 项**已删除**（`forge.py ui` 现在是「认不出这个命令」）；
2. 只读禁区名单已提进内核 `forge/guard.py`（`ui.py` 里那份是旧的，没跟着改）；
3. 前端路径变了（`assets/工作台/` → `弃用/工作台/前端/`）。

## 要把它开回来（真需要时）

1. `ui.py` 拷回 `forge/`；`前端/` 三个文件拷回 `assets/工作台/`。
2. `ui.py` 顶部把 `READONLY = [...]` 与 `readonly_reason()` 换成 `from . import guard`、
   用 `guard.READONLY` / `guard.readonly_reason` —— 只读禁区的**唯一真相**现在是 `forge/guard.py`。
3. `forge.py` 里把 `cmd_ui` 加回去（没有 git，只能照 `cmd_domains` 那样的写法重写一遍，
   它本来就只有十几行），命令表里补 `"ui": cmd_ui,`。

> 只想**看**这张界面长什么样：直接用浏览器打开 `前端/index.html`。
> 会因为没有后端而读不到卡，但样式与骨架都在。
