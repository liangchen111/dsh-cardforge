# 装完怎么验（照着点，一条一条打勾）

> 这份给**使用者**：插件装好之后，花十分钟把该出现的东西都点一遍。
> 出了毛病先翻最后一节的对照表 —— 九成的坑都在那几条里。

前提：ElecKoi 能上网（或镜像源已经同步）。**不需要**提前准备 Python ——
插件会自己去常见位置找；真找不到，它会在返回里说清找过哪些地方。

---

## 一、装（3 条）

- [ ] **1. 添加插件**

  侧栏「插件」→「添加插件」→ 贴包名 → 安装：

  ```
  dsh-cardforge
  ```

  报「找不到这个包」＝插件管理器默认用的那个镜像源还没抓到这个版本（新发布有几分钟延迟）。

- [ ] **2. 完全退出 ElecKoi，再打开**

  插件**只在宿主启动时载入**。装完不重启，工具和预设都不会出现。

- [ ] **3. 看插件列表**

  侧栏「插件」里应该多出 **制卡工坊**，简介是「给会话里的 AI 一个 cardforge 工具……」。

---

## 二、工具在不在（1 条）

- [ ] **4. 新开一个会话，对 AI 说**

  「用 cardforge 跑一次 `["--help"]`」

  应该回一整页命令表，最后一行是 `[exit 0]`。

---

## 三、创作预设装没装（2 条）

- [ ] **5. 预设管理器 →「创作预设」分类**

  列表里应该多出 **制卡助手**，而且是「使用中」。

- [ ] **6. 点开「制卡助手」**

  - 「使用说明」里是**四句话**（不是空的）；
  - 「预设提示词」应该显示 **21** 条；
  - 「工具」1 个 ·「预设正则」0 个。

---

## 四、真做一张卡（4 条，端到端）

- [ ] **7. 先把当前创作预设换成「制卡助手」，新开一个会话**，说

  「我要做一张都市怪谈的卡」

  它应该**先问你两个问题**（想让人体验什么 / 什么调子），而不是直接写正文。

- [ ] **8. 让它把工程落下来**

  它应该用 `cardforge` 建卡、落规划书；卡做在 `我的文档\ElecKoi卡库\` 下（默认位置，
  第一次会自动建）。

- [ ] **9. 让它一次落成**

  返回里应该有「条目 N · 分组 M · 变量 X · 正则 Y」，外加一行 **体检 ok（0 错 0 警告）**。

- [ ] **10. 出成品并导入**

  让它跑 `png` 与 `preset`，`成品\` 下应该出现 `.card.png` 与 `.preset.png` 两个文件。
  把 `.card.png` 当角色卡导进 ElecKoi —— **能打开、开场白正常**，就算整条路通了。

---

## 五、出问题时对照表

| 症状 | 多半是因为 | 怎么办 |
|---|---|---|
| 添加插件报「找不到这个包」 | 镜像源还没同步到这个版本 | 等几分钟；或把安装源切成官方源 |
| 插件列表里没有「制卡工坊」 | 装完没重启宿主 | 完全退出 ElecKoi 再打开 |
| AI 说没有 `cardforge` 这个工具 | 同上 | 重启之后**新开**一个会话 |
| 报 `spawn python ENOENT` | 这台机器没装 Python，或装了没进 `PATH` | 装一个 Python（安装时勾 **Add to PATH**），再重启 ElecKoi |
| 报 `No module named 'yaml'` | 找到 Python 了，但它没有 PyYAML | `pip install PyYAML`，再重启 |
| 预设列表里没有「制卡助手」 | 没重启 / 初始化时把 `installPreset` 设成了 `false` / 这是在纯 DSH 里（没有预设这回事） | 重启；或手动导 `制卡助手.preset.png`（导入时**分类必须选「创作预设」**） |
| 预设装上了，但当前不是它 | 你当时用的创作预设不是官方默认那个 —— 插件**故意不抢** | 自己点一下「使用中」 |
| 界面显示成 `--` / 变量读不到 / 面板一片空 | 界面层的静默失败族（外壳、桥、变量，三处断哪一处都长这样） | 看 `文档/插件-DSH.md`，以及规程里的「前端 · 换宿主最容易死在哪」 |

---

## 六、不想装插件的人怎么办

预设和角色卡**只认本机文件**，所以还有两条不装插件的路：

1. 拿 `制卡助手.preset.png` → 预设管理器 →「导入预设」→ **分类选「创作预设」**；
2. 拿 `制卡助手.card.png` → 当普通角色卡导入（手机端「导入角色」也认这张）。

这两个文件都在发布包里（`向导/制卡助手/成品/`）。装上插件就不用手动导，插件会替你装好。

> **这两个 PNG 不是图片，是单文件卡 / 预设。** 直接当图片打开只会看到封面 —— 要拿去导入。
